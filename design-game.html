LORE 1. 世界观与隐喻

你扮演一名从国内出发的建站冒险者。目标不是打怪掉金币，而是在「搜索之海」里立起自己的灯塔站点，让谷歌的航船（爬虫）发现你，再把访客变成补给（广告/订阅）。

🏝️ 岛屿 = 关卡

序章营地 → 站一新手岛 → 站二蓝海岛 → 站三内页群岛 → 变现港 → 放大航线。

⚔️ 战斗 = 实战任务

注册域名、上线页面、GSC 验证、外链、看数据——每完成一件，勾选一次「出击」。真动作在站外做，游戏里记账。

🎁 掉落 = 知识补给

每周一刷新「限时事件」：新词技巧、官方文档变更、托管坑点。读完可领少量 XP。

一句话定位：像《塞尔达》小地图 + 《习惯 RPG》打卡，而不是重度数值网游。爽点来自「解锁下一座岛」和「真实站点有收录」。

LOOP 3. 游戏循环

flowchart TD A[打开存档 · 看 HUD] --> B[选当前岛屿] B --> C[接取/查看任务] C --> D[离开游戏去做真建站] D --> E[回来勾选完成] E --> F[结算 XP · 连击 · 成就] F --> G{Boss 条件达成?} G -->|否| B G -->|是| H[过场动画 · 解锁下岛] H --> B I[周一事件刷新] -.-> C

核心诚实点：游戏不能替你建站；勾选等于你承认「线下这步做完了」。可后续加「备注 URL」防自己骗自己，仍属可选。

SYS 4. 系统：XP · 体力 · 成就

系统作用规则建议
XP / 等级 成长感 小任务 10～25；Boss 40～60。等级只改称号与头像边框，不锁内容（防挫败）。
连击 Streak 养成节奏 当天任意勾选或领取事件奖励即 Continuity；断一天重置。可设「保护符」一周一次（可选）。
体力（可选） 防一次勾爆 每日自动回满 5 点；每勾 1 任务耗 1。若觉得烦，MVP 可关掉，只留 XP。
成就徽章 里程碑橱窗 例：第一次被 site: 收录、第一次有曝光、第一次外链、读完 4 周补给…
库存（轻） 收集欲 不设交易。收集「情报卷轴」（补给已读）、「工具图鉴」（用过 Cloudflare/GSC 等打卡）。
反沉迷数值：不要做付费抽卡、不要随机掉落决定进度。解锁只看主线 Boss 是否完成。

QUEST 6. 任务面板交互

任务卡字段

标题（游戏化）· 真实动作说明 · 推荐工具 · 完成标准 · XP · 主线/支线/Boss 标签 · 常见坑。

勾选反馈

短振动式闪动（CSS）+ XP 飘字 + 进度条跳动。Boss 完成：全屏短过场 1.5s（可跳过）。

防误触

取消勾选可撤回 XP；重置存档需输入「重置」或二次确认。

诚实模式（可选）

Boss 勾选前弹窗：粘贴站点 URL 或一句话证据（仅存本地）。

EVENT 7. 每周事件补给（游戏化）

  • UI 名称：「周一港口商船」——到港刷新 1～3 个卷轴。
  • 操作：阅读摘要 → 点「收入图鉴」→ +5 XP（每条仅一次）。
  • Grok Bot 职责：改 WEEKLY_UPDATES 数据；有更新时在聊天发摘要并附文件；无更新保持安静。
  • 例行：每周一上午（已创建、目前暂停，开工后再开）。

FX 8. 视听与动效（克制版）

元素建议避免
视觉风格深色游戏 UI + 金/青高对比；图标可用 Emoji 或简单 SVG刺眼霓虹、过密粒子
动效解锁弹跳、XP 数字上浮、地图节点点亮长过场无法跳过
音效可选：勾选叮、通关短和弦；默认静音，需用户打开自动循环 BGM 打扰
无障碍对比度达标、减少动态选项、键盘可操作仅靠颜色区分状态

TECH 9. 技术落点（仍本地单页）

  • 单文件或小目录：index.html + 可选 assets/（音效、svg）。
  • 数据：CHAPTERS / QUESTS / ACHIEVEMENTS / WEEKLY_UPDATES。
  • 存档：localStorage['gefei-quest-save-v1']。
  • 零构建；尽量零 CDN，保证离线打卡。
  • 与上一版设计的内容骨架兼容：关卡仍是哥飞公开方法，只是外壳更像游戏。
