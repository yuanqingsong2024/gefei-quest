## 原则（写死）

1. 站二目标 = **一词一岛**：一个需求词 → 一页承接 → 合法分发 → 看 GSC。
2. **不换主词**直到有曝光数据；别同时开五个词。
3. 外链只走合法导航/目录/社区；不买链、不群发。
4. 诚实勾选：没数据不硬勾 Boss。
