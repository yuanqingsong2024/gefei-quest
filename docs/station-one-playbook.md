# 站一作战手册（可打印）

> 勾选以游戏内存档为准；本页给人对照纸质勾选。

---

## 原则（写死）

1. 站一目标 = **学会上线 + 被收录**，不是赚钱。
2. **1 个英文主词**（可为自创品牌词），上线前不改。
3. 先发布再打磨；HTTPS 可访问即过关。
4. 不抄黑帽外链、不空站申广告、不一站暴富幻想。

## Day 7 · 呼名 / 复查

- [ ] 搜品牌词或 `site:你的域名`；能找到则勾 Boss（`q-s1-boss`）
