# Phase 15 · 平台变现（国内 + 海外）

## 结构
资源库下的新栏目「平台变现」：
- `#pm` 总览：两大组（国内 / 海外）、分类入口、新手怎么选、来源与核实说明
- `#pm-<分类>` 分类页：对比表 + 每个平台卡片
- 国内：图文/自媒体（含微博）、长视频、短视频、直播、网文/小说、漫画/漫剧、短剧、音频/播客、知识付费、闲鱼/素材
- 海外：视频（YouTube、TikTok、Twitch）、社交（X、Instagram/Facebook、Pinterest）、写作与会员（Medium、Substack、Patreon）

## 每个平台
变现方式 · 门槛 · 分成/计费规则（**每个数字都标来源与日期**；没有可靠来源写「官方未公开/以后台为准」）· 实操方案 · 适合谁 · 风险/违规红线 · 来源链接（附核实状态）· 更新日期。海外平台另注：大陆能否访问、收款方式。

## 原则
- 不编数字；来源冲突时同时列出并写「以后台为准」。
- 不承诺收益；只写合法路径；不提供翻墙或绕过地区限制的方法。
- 来源链接在 `tools/check-platform-links.js` 中核实（200 / 被拦截注明）。

## 入口
资源库顶部横幅、首页卡片、页脚、全站搜索（每个平台一条）、更新日志 + daily.json。
