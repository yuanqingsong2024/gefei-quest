## 原则（写死）

1. 空站 / 采集站不宜申广告；先有原创内容与可用导航。
2. 收入案例 ≠ 保证；门槛与政策以官网为准。
3. 第一版只定一个方向：只练收录 / 先接 AdSense / 极简付费。
4. 信任页（About / Contact / Privacy）像正经项目，再谈申请。

## AdSense 自检（公开摘要 · 非官方）

> 最终以 [Google AdSense 帮助](https://support.google.com/adsense/) 为准。

- [ ] 内容原创、有实质信息（非占位/采集）
- [ ] 导航可用；移动端可读
- [ ] About / Contact / Privacy 齐全且信息真实
- [ ] 托管条款允许商用（若挂广告）
- [ ] 未承诺收益；未买假流量冲门槛
- [ ] 空站 / 薄站先别申；先养内容与收录
