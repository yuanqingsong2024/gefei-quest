## 原则（写死）

1. 站三目标 = **扩内页 + 内链**：3+ 长尾页，围绕主站能力，不跑偏。
2. 各页独立 title / 唯一 h1；拒绝纯模板堆砌。
3. 首页链出内页；内页锚文本自然指回主词。
4. sitemap 更新并提交；诚实勾选 Boss（多页收录 + 点击趋势）。
