---

## 原则（写死）

1. **一词一船**：下一站仍只打一个主词；勿同时开十个坑。
2. **反空壳**：第一站未跑通（收录 + 有观察数据）前，不铺大量空壳站。
3. **可复用船体**：复制的是部署步骤、页面骨架与检查清单，不是抄内容。
4. 收入案例 ≠ 保证；放大是节奏与模板，不是一夜暴富按钮。
