# 出海小站练站营 · Phase 2 路线图

> 日期：2026-10-16（Asia/Shanghai）  
> 状态：**已完成** · 默认决策已锁定 · Phase 3 见 `PHASE3-ROADMAP.md`  
> 线上：https://yuanqingsong2024.github.io/gefei-quest/

---

## 1. 目标（2–4 周）

把练站营从「游戏打卡 + 资料柜」升级为 **学习 + 可落地执行中枢**：

1. **站一闭环可落地**：序章→站一的 Day1–7 固定清单 + 可下载英文单页模板，用户打开就能改词部署。
2. **资源库可长期扩**：`resources.html` 为枢纽；数据驱动（现有 `TRY_CHANNELS` / 后续 JSON 配方），扩类目不改 UI 骨架。
3. **少打断用户决策**：产品路径写死默认；Bot / 页面不抛「选 A 还是 B」控件；需要拍板的项由本路线图锁死。

非目标（本 Phase **不做**）：

- 收益保证、付费课搬运、账号云同步、排行榜。
- **周一「知识补给」Bot 例行**：代码与仓库 **不启用**；仅文档注明「需用户说恢复」。暂停中的 Bot 侧 routine 由用户日后明确说「恢复周一补给」后再开。

## 3. 架构决策（已锁定 · 无备选）

| # | 决策 |

| D9 | 本工作流 **禁止** 再向用户发选择 widget；执行顺序严格 T46→… |

## 4. 成功标准（定性）

- 新人只看作战室 + starter README，**不点选分支**，能在约 7 天内勾完站一主线（Boss 可等收录）。
- 资源库一页能找到：工具、托管、变现、路径、闲鱼、技巧、同路人、starter、手册。
- 刷新 / 换 Tab 后作战室与任务板勾选一致。
- 文档写清 Phase 2 任务 ID，后续会话可无提问续做。
