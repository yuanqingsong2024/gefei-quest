### 1.2 主要混乱点
1. **H1 与菜单名不一致**：17 个子页面的 H1 是分组名（实战作战室 / 我的进度 / 资源库 / 学习路线），不是用户点的菜单项名（如点「选词练习板」看到的大标题是「实战作战室」）。
2. **同一分组三个名字**：顶栏「实战」、页面「实战作战室」、底部栏「作战室」；「资源」/「资源库」；「学习」/ 底部「路线」。
3. **「实战」下拉 9 项、混了三类东西**：7 天日程（学习/计划）、建站工具（实施）、每日赚钱榜（赚钱），还挂着已暂停的「每周补给」。
4. **赚钱内容分散**：每日赚钱榜在「实战」，平台变现在「资源」，数据分析在「我的」，复盘在「实战」。
5. **孤儿页面**：#me-sites（我的站点台账，在 FLOW 主线上）和 #changelog 不在任何下拉菜单；站二~放大只能从作战室标签进。
6. **高亮缺失**：#war-s2…#war-x、#lib-*、#pm-*、#guide-*、#me-sites、#changelog 打开时下拉里没有对应高亮项；#start / #guides / #weekly 底部栏无高亮。
7. **底部栏与顶栏不一致**：底部 5 项（首页/路线/作战室/资源库/我的）与顶栏 6 项（首页/新手引导/学习/实战/资源/我的）名字和分组都不同，缺新手引导。
8. **面包屑层级错位**：面包屑中间层是旧分区名（实战作战室、资源库、我的进度），不是顶栏分组；手册页缺「学习」。
9. **页脚和网站地图与顶栏三套分组**：页脚把「手册与模板」「每周补给」放在「资源」；网站地图「主要页面」与「实战与工具」重复列同一批页面，「我的」组里又放了手册与模板；页脚「新手引导」「新手导览」都指向 #start。
10. **FLOW 来回跳菜单**：下一步顺序 选词(实战) → 实操助手(实战) → 站点台账(我的) → 发布(实战) → 分发(实战) → 工作台(实战) → 数据分析(我的) → 复盘(实战) → 赚钱榜(实战) → 平台变现(资源)。
11. **图标重复/含义不清**：工作台与作战室都是 target；学习统计与数据分析都是 chart；学习分组、学习路线、网站地图都是 map；每周复盘与更新日志都是 bulb；首页 学/做/赚 卡片用实心黄色大方块，线条图标小且被裁切。

## 2. 新信息架构（唯一配置源：`js/nav.js` 的 `SITE_NAV`）

原则：每个页面只在一个菜单里；菜单项名 == 页面 H1 == 页面标题；下拉项 = 图标 + 名称 + 一行说明；所有子路由都高亮父级和对应项；子页面在顶栏下方显示面包屑「首页 / 分组 / 页面」；底部栏与顶栏同一组；FLOW 顺序 == 菜单顺序；页脚和网站地图都从 `SITE_NAV` 生成。路由 hash 不改（只重新分组），旧别名继续可用，存档 key 和任务 id 不改。

| 顶栏 | 落地页 | 下拉（顺序即 FLOW 顺序） |
|---|---|---|
| 首页 | #home | — |
| 新手引导 | #start | — |
| 学习 | #path | 学习路线 #path · 任务清单 #path-quests · 手册与模板 #guides（含 #guide-*）· 资源库 #lib（含 #lib-*）· 每周补给 #weekly（已暂停，放最后） |
| 实施 | #war | 7 天作战日程 #war（含 #war-s2/-s3/-m/-x，原「实战作战室」改名）· 选词练习板 #war-keywords · 站一实操助手 #war-kit · 我的站点台账 #me-sites · 发布上线 #war-publish · 内容分发 #war-share · 工作台 #work |
| 赚钱 | #war-rank | 数据分析 #me-analytics · 每周复盘 #work-review · 每日赚钱榜 #war-rank · 平台变现 #pm（含 #pm-*） |
| 我的 | #me | 我的进度 #me · 学习统计 #me-stats · 账号中心 #me-accounts · AI 设置 #me-ai · 更新日志 #changelog |

- 页脚「网站地图」和 #dev 不进顶栏（页脚链接）。页脚只保留一条「新手引导」，导览重播用按钮文字「重播新手导览」并说明。
- 底部栏（≤640px）：首页 / 新手 / 学习 / 实施 / 赚钱 / 我的（6 项，同一图标）；搜索留在顶栏右侧搜索按钮。
- FLOW：start → path → path-quests → war → war-keywords → war-kit → me-sites → war-publish → war-share → work → me-analytics → work-review → war-rank → pm（guides / lib / weekly / 我的 子页不在主线，下一步按钮指向所在分组的下一项或 JUMP）。
- 新别名：`learn→path`、`do→war`、`practice→war`、`earn→war-rank`、`money→war-rank`、`res→lib`。

## 3. 统一图标（`js/icons.js`）

- 一套风格：24px 网格、stroke-width 1.75、圆角端点与拐角、无填充（必要时 0.15 透明度色块），全部在 2px 安全边距内，不裁切。
- 分组图标：首页 home · 新手 flag · 学习 book-open · 实施 tools（扳手+螺丝刀）· 赚钱 coin · 我的 user。
- 页面图标（不重复）：学习路线 map · 任务清单 checklist · 手册与模板 file-text · 资源库 archive · 每周补给 calendar · 7 天作战日程 calendar-check · 选词练习板 tag · 站一实操助手 wand · 我的站点台账 ledger · 发布上线 rocket · 内容分发 send · 工作台 dashboard · 数据分析 chart-line · 每周复盘 clipboard-check · 每日赚钱榜 trophy · 平台变现 wallet · 我的进度 gauge · 学习统计 bar-chart · 账号中心 key · AI 设置 sparkle · 更新日志 history · 网站地图 sitemap。
- 同一概念同一图标（导航、下拉、面包屑、区块头、卡片、网站地图、底部栏都从 `SITE_NAV` 取 icon）。
- 功能卡片图标：柔和色块（分组色 12–16% 透明底 + 1px 同色描边，44–52px 圆角方块），图标 24–28px 居中；不再用实心黄色大方块。三个分组各有一个色调（学习 蓝、实施 青/绿、赚钱 金），对比度达标。
- 重新生成 `icons.html` 预览：全部图标网格 + 名称 + 分组色块示例。
