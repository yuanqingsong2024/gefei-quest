# Phase 9 · 实操工具（站一实操助手 / 选词练习板 / 我的站点台账）

目标：让站从「看」变成「帮你干」。全部纯前端、无构建、file:// 可用，数据只存本机浏览器（localStorage `gefei-quest-save-v1`，仅追加字段）。

## 1 站一实操助手
- 表单：主词/品牌名、一句话介绍（EN）、域名、联系邮箱；实时预览 title / meta description / h1 / slug，带字数与规则（title ≤60 且含主词；description 120–160；h1 唯一且含主词）。
- 下载：自写零依赖 ZIP（store 模式 + CRC32）打包 index.html + robots.txt + sitemap.xml；也可单独下载每个文件。
- 上线自查表 6 项，勾选存 `kit.checks`，每项链到站一手册对应段；与任务等价的项（上线↔q-s1-02，统计↔q-s1-03，GSC↔q-s1-04，sitemap↔q-s1-05）勾选时同步勾任务（只勾不撤）。

## 2 选词练习板
- 字段：关键词、来源、搜索量区间、SERP 前10 大站数、论坛/新站数、意图、备注、星标。
- 评分（启发式，非保证）：
  `分 = 大站分(10−大站数)×4 + 弱站分 min(论坛新站数,5)×4 + 量分(无0/<100 4/100–1k 10/1k–10k 14/10k+ 8) + 意图分(工具 12/对比 8/信息 6/交易 4)`，满分 100。
  ≥65 适合练手；40–64 可以试；<40 先换长尾。
- 快捷链：Google 搜索、Google Trends、Keyword Planner。排序/筛选/编辑/删除/星标、设为站一主词（写入实操助手）、设为站二目标词（`keywords` 内 `s2Target`）、导出 CSV。

## 3 我的站点台账
- 站点：名称、域名、主词、对应站、上线日、状态、托管、变现方式。
- 月度记录：月份、曝光、点击、收入 USD/CNY、备注（手填，不接 GSC API）。
- 汇总卡 + 手绘 SVG 折线（点击、收入）；CSV 导出；随存档导出导入；首页进度快照显示站点数与最近月合计。
