# 完整主线说明（挖词→上站→变现→收款）

> 配套：[手册列表](../index.html#guides) · [站一手册](./station-one-playbook.md) · [变现手册](./monetize-playbook.md) · [选词练习板](../index.html#war-keywords) · [作战室](../index.html#war)  
> 本文是**总览**：把「找词 → 建站 → SEO → 赚钱 → 收款」串成一条可照着做的主线。各阶段细节仍以对应作战手册为准。  
> **学习公开方法论，不是付费社群内容。** 不承诺收益；案例 ≠ 你的结果。

---

## 原则（写死）

1. **一词一站**：全站围着 1 个英文主词（站一甚至可用自创品牌词）。
2. **先上线再打磨**：HTTPS 能打开就算过关；别在本地磨一个月。
3. **空站 / 采集站不申广告**：先有原创内容、可用导航与信任页。
4. **案例 ≠ 保证**：别人晒的收入不是你的预期；政策与门槛以官网为准。
5. **先跑通一站再放大**：有真实收录或数据后再复制流程。
6. **不卖账号、不代领**：闲鱼等渠道只卖你自己跑通过的非实物方案 / 手册。

## 第 4 步 · 赚钱方式

按新手常见顺序（第一版**三选一**，不要并行堆一堆）：

| 方式 | 适合阶段 | 钱从哪来 |
|------|----------|----------|
| **Google AdSense** | 有原创内容、信任页齐全后 | 访客点 / 看广告，Google 给你分成 |
| **联盟**（如 Amazon Associates） | 有产品评测 / 比较意图页 | 用户经你链接购买，品牌给你佣金 |
| **数字产品 / 小工具付费** | 能解决一个痛点 | 用户付钱订阅或买一次 |
| **闲鱼非实物方案** | 把你跑通过的玩法写成指南卖 | 买家付款买「方案 / 手册」（不卖账号、不代领） |
| 更高门槛广告网（Journey / Mediavine / Raptive 等） | 流量或收入到公开门槛后再谈 | 仍是广告分成，费率通常更好 |

## 第 5 步 · 收款到自己账户

### A. 广告分成（AdSense 主线）

1. 站点过审、贴上广告代码  
2. 余额累计到提现门槛（公开常见约 **$100**，以 AdSense 后台为准）  
3. 在 AdSense → 付款里绑定**收款方式**（常见银行电汇等到你名下账户；选项以你账号所在国家 / 地区后台为准）  
4. 到账周期按 Google 付款日程；首次常要核对税务 / 身份信息  
5. 大陆用户实务上常卡在「能绑什么收款账户」——用支持美元收款的银行账户，或**合规**跨境收款通道；**以 AdSense 后台可选方式为准**，不要用违规代收  

### B. 直接向用户收款（付费工具 / 数字产品）

1. 选收款通道：海外常见 Stripe、PayPal 等；大陆个人直连 Stripe 往往很难，需要合规主体或正规替代通道（能提现到你本人卡的）  
2. 用户付款 → 通道余额 → 按规则提现到银行卡  
3. 闲鱼卖方案：钱走闲鱼订单结算，按平台规则提现到你绑定的支付宝 / 银行卡（注意平台规则与禁区）  

### 一句话对照

| 钱的类型 | 路径 |
|----------|------|
| **广告钱** | Google / 联盟平台 → 你的收款账户 |
| **产品钱** | 用户 → Stripe / PayPal / 闲鱼等 → 你的卡 |
