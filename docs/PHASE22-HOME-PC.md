# Phase 22 · 首页桌面版重排

问题（桌面 1024–1366px，见 p23-mine-home-next.png）：首屏约 430px，大部分是空的暗色背景；标题和副标题偏小，挤在左边，右半边只有背景图；下方的「下一步」横条和首屏按钮重复（两个「新手引导」按钮）；首屏看不到用户希望突出的 Top-10 赚钱榜；「问 AI」按钮压在横条边上。

## 方案（桌面 ≥1024px；移动端保持可用、紧凑）
1. **两栏首屏**：放进居中容器（max-width ~1200px，与全页其他区块同一容器）。
   - 左栏：H1「做英文出海小站」（约 44–52px）、1–2 行站点介绍、学习 → 实施 → 赚钱 三步小条、主按钮。
   - 右栏：「今日赚钱榜 Top 3」预览卡，数据与首页榜单同源（真实 rank 数据），显示日期和「看完整 Top 10」链接（滚动到榜单区块）。
   - 首屏高度约 360–420px，不留大块空白；保留灯塔背景，在卡片后面压暗/模糊以保证对比度。
2. **「下一步」并入首屏**：主按钮的文字和目标来自 `QuestHome.nextStep(save)`（新访客：「我是新手，从这里开始」→ #start；有进度：如「继续：挑一个关键词」）。次按钮：「直接看今日赚钱榜」。桌面去掉单独的全宽「下一步」横条；如果移动端保留，不得与主按钮重复。
3. **首屏下方统一宽度和间距**：「这个网站怎么用」（桌面三张卡并排：学习/实施/赚钱）→ 完整 Top-10 榜（2 列）→ 为什么做 + 常见问题 → 页脚。所有区块对齐同一容器边缘。保持先介绍，不做功能网格。
4. **「问 AI」按钮**：不压住内容边缘或卡片；页面底部留足 padding。
