## A. 免费/试用工具与额度

### A1. Google Search Console（必装）
- **是什么**：谷歌官方站长工具：曝光、点击、索引、sitemap、CWV。
- **怎么试**：① 打开 [GSC](https://search.google.com/search-console/about) → ② DNS/HTML 验证域名 → ③ 提交 sitemap。
- **注意**：只反映搜索表现；全站流量另装统计。免费。

### A2. Google Analytics 4
- **是什么**：免费流量与转化分析。
- **怎么试**：① 建 GA4 媒体资源 → ② 贴测量 ID 到站点 → ③ 实时报告确认有命中。
- **注意**：隐私政策页建议说明统计 Cookie；免费额度对小站足够。

### A3. Microsoft Clarity
- **是什么**：免费热力图与会话回放（微软）。
- **怎么试**：① [Clarity](https://clarity.microsoft.com/) 建项目 → ② 贴脚本 → ③ 有访问后看热力。
- **注意**：官方称长期免费、无流量上限宣传；不替代关键词/排名工具。

### A4. Bing Webmaster Tools
- **是什么**：必应站长：索引、sitemap、部分关键词/外链洞察；可从 GSC 导入。
- **怎么试**：① [Bing Webmaster](https://www.bing.com/webmasters) → ② 验证或 GSC 导入 → ③ 交 sitemap。
- **注意**：份额小于谷歌，但交图成本极低，阿小信等实践常提「多引擎交图」。

### A5. Google Keyword Planner
- **是什么**：谷歌 Ads 后台关键词想法与量级估计。
- **怎么试**：① 开 Google Ads 账号 → ② 工具 → Keyword Planner → ③ 搜种子词。
- **注意**：可能要求完善 Ads 账户；量级是区间估计。免费查词，不等于要烧广告费。

### A6. Google Trends
- **是什么**：相对搜索热度与季节性。
- **怎么试**：对比 2–3 个候选词近期曲线，避开已死趋势。
- **URL**：https://trends.google.com/

### A7. Ahrefs Free（原 Webmaster Tools）
- **是什么**：验证自有站后可用 Site Explorer / Site Audit / Web Analytics 等有限免费功能。
- **怎么试**：① [ahrefs.com/free](https://ahrefs.com/free) 注册 → ② 验证站点 → ③ 看自站关键词与审计。
- **注意**：竞品全量数据多在付费档；免费档以「自己的站」为主。额度以官网 2026 说明为准。

### A8. Keyword Surfer（Chrome 扩展）
- **是什么**：在谷歌 SERP 上叠加估计搜索量与相关词。
- **怎么试**：商店安装 → 正常搜词 → 看侧栏/标注。
- **注意**：估计值非官方；适合快速扫词。

### A9. PageSpeed Insights / Lighthouse
- **是什么**：Core Web Vitals 与性能诊断（谷歌）。
- **怎么试**：贴 URL 测桌面+移动；优先修红项。
- **URL**：https://pagespeed.web.dev/

### A10. Google Rich Results Test
- **是什么**：结构化数据/富结果检测。
- **怎么试**：有 FAQ/HowTo/Product 等 schema 时再测。
- **URL**：https://search.google.com/test/rich-results

### A11. Screaming Frog SEO Spider（免费档）
- **是什么**：桌面爬虫：断链、title、状态码。
- **怎么试**：装桌面版 → 免费档约 500 URL/次爬 → 导出标题重复项。
- **注意**：大站需付费；小站练手够用。

### A12. Ubersuggest / AnswerThePublic 等 freemium
- **是什么**：有限次/日的关键词与话题灵感。
- **怎么试**：免费额度内扫 1–2 个种子词即可，勿当主数据源。
- **注意**：日限常变；主数据仍以 GSC + SERP 实看作准。

## B. 域名/托管羊毛与低成本起步

### B1. Cloudflare Pages（强烈推荐练手）
- **是什么**：静态站免费托管；带宽对静态资源很慷慨；自定义域名 + HTTPS。
- **怎么试**：① Cloudflare 账号 → ② Pages 连 Git 或直传 → ③ 绑域名。
- **注意**：文件数/单文件大小有上限；Functions 另计 Workers 配额。商用前读条款。调研摘要日 2026-10。

### B2. GitHub Pages
- **是什么**：公共仓库免费静态托管（本练站营即此路径）。
- **怎么试**：仓库 Settings → Pages → 选分支；或 `docs/` / Actions。
- **注意**：Free 公共仓；带宽有软上限；是否适合「纯商用站点」以 GitHub 条款为准，广告站更常见做法是 CF Pages / 自有 VPS。

### B3. Netlify / Vercel 免费档
- **是什么**：Jamstack 部署、预览环境。
- **怎么试**：连 Git 一键部署；自定义域名。
- **注意**：Netlify 新账户多为 credit 制（2025 起调整）；Vercel Hobby 常标非商用限制——**计划 AdSense 前必读条款**。额度以官网为准。

### B4. Cloudflare R2 免费档
- **是什么**：对象存储；出站流量常宣传免费（适合大资源）。
- **怎么试**：开 R2 → 建桶 → 自定义域；超免费档才计费。
- **注意**：首次可能要绑卡；免费额度约存储 + 操作次数（以 Cloudflare 价目为准）。小站纯 HTML 通常用不到。

### B5. 便宜域名（.xyz / .top 等）公开行情
- **是什么**：首年促销常见 $1–3；**续费往往大幅上涨**。
- **怎么试**：比价 Porkbun / Namecheap / Cloudflare Registrar / Spaceship 等；看清续费价再下手。
- **注意**：练手站可用便宜后缀；长期品牌站优先看 `.com` 等与续费。价格日变，以注册商结账页为准（本笔记参考 2026-10 公开比价）。

### B6. Cloudflare Registrar
- **是什么**：按成本价卖域名、无加价续费宣传。
- **怎么试**：域名转入/新购（部分 TLD）；DNS 与 Pages 同账号省事。
- **注意**：TLD 覆盖不如综合商全。

### B7. 零成本起步路径（推荐顺序）
1. GitHub Pages 或 CF Pages 上线 HTTPS  
2. 有流量/变现意向再买域名绑上  
3. 广告前核对托管是否允许商用  

### B8. 免费 SSL / CDN
- Cloudflare 代理或 Pages/托管商自带证书即可；不必另买 SSL 证书给小站。

## C. 变现渠道可尝试（公开门槛摘要）

> 门槛会改；申请前打开官网帮助页核对。以下为 2026-10 公开信息摘要。

### C1. Google AdSense（新手第一站常见）
- **门槛**：无公开流量下限；需约 18+、可改源码、原创合规内容。
- **怎么试**：读 [资格要求](https://support.google.com/adsense/answer/9724) → 站像正经项目（信任页+实文）→ 申请。
- **注意**：空站/采集易拒；提现门槛约 $100；**别点自己广告**。

### C2. Amazon Associates（联盟）
- **门槛**：无统一公开流量下限；按合资格购买抽佣。
- **怎么试**：有产品评测/比较意图页时再申；披露联盟关系。
- **注意**：需真实有用内容；纯空壳难过审/难转化。

### C3. Journey by Mediavine
- **门槛**：公开资料约 **1,000 Tier-1 sessions / 30 天** 档（摘要）。
- **怎么试**：流量到了再看 [Mediavine 帮助](https://help.mediavine.com/)；新手仍先 AdSense。
- **注意**：门槛以官网为准。

### C4. Mediavine Official
- **门槛**：约 **年广告收入 ≥ $5,000**（2026 路径调整后按收入分档，摘要）。
- **怎么试**：放大期再关注；先把一站做稳。

### C5. Raptive（原 AdThrive）
- **门槛**：约 **25k PV/月** + 较高比例 Tier-1 + 域名年龄等（第三方目录摘要）。
- **怎么试**：远高于练手站阶段；记个目标即可。

### C6. Ezoic
- **门槛**：公开常提较高 MAU；有 Incubator 等较低入口（以官网为准）。
- **怎么试**：读官方要求再决定是否早接；有人用其优化 AdSense，也有体验褒贬不一。

### C7. 其它公开路径（意识级）
- **数字产品 / 小工具付费**：Stripe 等（小树等公开复盘常提收款链路）。
- **Newsletter 赞助**：先有订阅再谈价；适合内容站后期。
- **Digistore24 / 垂直联盟**：选与站点意图相关的产品；披露关系。
- **YouTube 广告分成**：另开频道；可与站点互导，非本营主线。

## E. 从同路人摘要摘出的可执行技巧（12 条）

1. **先写受众再选题**（子木）— 避免蹭无关热词把主题做散。  
2. **SERP 嗅探** — 目标词前 5–10 条：类型、标题模式、可超越点。  
3. **长尾 / 蓝海老词 / 新词分档** — 新人优先低竞争有一点量的词。  
4. **MVP 快上线**（阿小信）— 先可访问再迭代，别在本地打磨半年。  
5. **多引擎交 sitemap** — GSC + Bing（+可选其它）成本极低。  
6. **日入 $1 当里程碑不是终点** — 心态锚点；案例≠保证。  
7. **别点自己的广告** — 政策与账户风险。  
8. **月报复盘**（小树）— 记下改站动作、GSC 点击、DR/领先指标。  
9. **信任页三件套** — About / Contact / Privacy；像正经项目。  
10. **8–15 篇实文再冲审**（公开拒审文经验）— 数量非唯一，质量与完整度更重要。  
11. **Content → Links → Technical**（Ahrefs）— 先去掉索引障碍。  
12. **people-first / 单页质量门槛**（Google）— 三秒说清干什么；有独特信息。

## F. 闲鱼非实物赚钱（单独一类）

> **定位**：不需要囤实物库存的闲鱼玩法——数字下载（一次做、多次卖）或技能换时间。  
> **原则**：原创 / 已授权 / 真实可交付；站内沟通与担保交易；不保证收益。  
> **规则摘要**：须对发布信息享有合法权利；禁侵权盗版、虚假宣传；禁学术/考试作弊等；游戏账号/点卡/游戏币等虚拟类目多属平台禁售或高风险——**本营不收录**。详见 [闲鱼社区卖家服务协议](https://terms.alicdn.com/legal-agreement/terms/platform_service/20220929192826912/20220929192826912.html) 与 App 内最新《信息发布规范》。鱼小铺/软件服务费比例会变（2026 公开调整过），报价时预留手续费。

### F0. 禁区（先划掉）

| 不做 | 原因（公开规则/法律常识） |
|------|---------------------------|
| 盗版网课、破解软件、未授权影视/电子书搬运 | 侵权；平台高压治理；有判例 |
| 学术代写、代考、假证假章 | 明确违禁 |

### F1. 数字商品（一次制作 · 多次售卖）

#### F1.1 原创 PPT / 简历 / Excel 模板
- **是什么**：自创或深度改版的模板包；买家下载即用。
- **为何无库存**：文件可无限复制，边际成本近零。
- **怎么试**：① 选一垂直场景（答辩/路演/应届简历）→ ② 做 1 套完整样例并截目录/效果图 → ③ 标题写「场景+交付格式」→ ④ 试价约 9.9–39 元观察曝光。
- **风险**：转卖他人付费模板=侵权；保留自己的创作过程（草稿/源文件）备查。

#### F1.2 Notion / 提示词 / 表格工作流包
- **是什么**：你整理的工作流模板、可复用 AI 提示词说明（非抄付费库原文）。
- **怎么试**：① 选一垂直（内容日历/出海选题板）→ ② 附使用说明 PDF/页 → ③ 写清交付方式（链接或文件）。
- **风险**：勿整份搬运付费提示词/课程讲义。

#### F1.3 设计源文件 / Canva 模板 / 调色预设
- **是什么**：自创海报模板、简约标识源文件、Lightroom/同类预设等。
- **怎么试**：① 预览图 3–6 张 → ② 注明商用范围与软件版本 → ③ 若含微调服务，单独写修改次数。
- **风险**：字体与素材须可商用或自绘；勿卖未授权品牌素材包。

#### F1.4 公开可商用资料的二次整理
- **是什么**：政府公开报告、CC0/开源说明文档等的编排合集（**不是**盗版网课网盘包）。
- **怎么试**：① 只收录可核验公开源并标注出处 → ② 详情写清「整理+索引」价值 → ③ 避免「全集破解」话术。
- **风险**：付费电子书/网课搬运是红线；灰色「学习资料包」易被下架。

### F2. 技能服务（时长换钱 · 轻/无实物）

#### F2.1 PPT 美化 / 定制排版
- **是什么**：客户给大纲或初稿，你负责结构与视觉。
- **怎么试**：① 作品集拼图作首图 → ② 详情七段：能交付 / 不接什么 / 分档价 / 交付物 / 修改政策 / 下单流程 / 案例 → ③ 先接 1–2 单练流程。
- **风险**：勿写「保证答辩过」「无限改」；交付留聊天与文件发送记录。

#### F2.2 简历优化
- **是什么**：结构、量化表述、排版；交付可编辑稿。
- **怎么试**：① 匿名前后对比样例 → ② 分档（基础改版 / 深度辅导）→ ③ 约定轮次与交稿日。
- **风险**：不承诺面试或录用结果。

#### F2.3 翻译校对 / 文案润色
- **是什么**：按字或按篇的轻服务。
- **怎么试**：① 标明语种与擅长领域 → ② 放 1 段对照样例 → ③ 写清时效与是否含排版。
- **风险**：法律/医学/会计等需资质的咨询不要硬接。

#### F2.4 Excel 自动化 / 小脚本交付
- **是什么**：公式模板、简单批处理脚本 + 使用说明。
- **怎么试**：① 30 秒演示动图/视频 → ② 写运行环境（Excel 版本/系统）→ ③ 交付文件+README。
- **风险**：禁隐私爬取、破解、外挂类工具。

#### F2.5 出海建站 / SEO 答疑（与练站营同路）
- **是什么**：选题、GSC、上线清单、信任页等陪跑答疑；用你自己的练手站当案例。
- **怎么试**：① 写清「答疑时长 + 是否出纪要」→ ② 定价按时段 → ③ 明确「方法陪跑 ≠ 收入保证」。
- **风险**：勿转售付费社群录音/讲义；案例收入 ≠ 买家收入。

### F3. 本周可试阶梯（新手）

| 日 | 动作 | 完成标准 |
|----|------|----------|
| Day 1 | 选定 1 个你**已经会**的交付物，做出可展示样例 | 有预览图或前后对比 |
| Day 2 | 写上架清单七段（见上 F2.1） | 文档齐全，可暂不点发布 |
