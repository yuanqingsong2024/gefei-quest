1. 一句话与目标

像《塞尔达》小地图 + 《习惯 RPG》打卡：建站冒险者在搜索之海立灯塔；主线三岛 + 每周港口商船。勾选 = 线下实战记账。

目标

  • 公开方法拆成可勾选任务；站一→二→三递进
  • 深色 HUD + 地图 + 任务板 + 成就 + 商船
  • localStorage；零部署；周更只追加数据
  • 高对比：金/青/近白正文在深底可读

非目标（MVP）

  • 无登录云同步排行榜；不代建站；无收益承诺
  • 无抽卡；体力默认关闭；无不可跳过长过场

4. 关卡与 Boss（摘要）

岛屿Boss演出
🏕️ 序章方向备忘（类型+主词）推开营地大门
🏝️ 站一品牌词能搜到站灯塔点亮
🌊 站二目标词曝光并向首页推进航道打通
🗺️ 站三多页收录+点击趋势群岛连线
💰 变现港变现路径选项（申请成功不强制）港口升旗
🚢 放大下一站可执行清单新航线解锁
完整每任务的 id / title / action / tools / doneCriteria / xp / required / boss 见 Markdown §7。

示例（站一 Boss）：BOSS 呼出你的名字 · +50 XP · 谷歌品牌词或 site: 找到自己。
